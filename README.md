# AI EQS Battle Simulator

Project testing out EQS capabilities in a BT driven AI vs AI Shooter

## 📖 About The Project

This repository contains the Unreal Project AI

The key feature is NPC combatants moving from cover to cover to attack other NPCs from enemy teams.
This Project was made in order to test the EQS capabilities and workflow.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

* **Unreal 5.8.3** installed.
* **Git** (for cloning the repository).

### Installation

1.  **Clone the repository:**
    ```sh
    git clone [https://github.com/DanielLyhus/AI](https://github.com/DanielLyhus/AI.git)
    ```

2.  **Open the project in Epic Games Launcher:**
    * Launch Epic Games Launcher.
    * Launch 5.8.3 Engine.
    * Click see all projects
    * Click Browse...
    * Find the Project folder and click open

4.  **Open the main scene:**
    * Once the editor is open, locate the main level file, All/Content/03_Levels and then open LV_01
